# 초기 무기 계열 무료화

CETME, HK33, M16, M60 계열 보병 무기는 클래스별 기존 가격보다 우선하여 **Lv0 / $0**으로 설정합니다. M16A1/A2/A3/A4, M60A2 및 위장색·총열·개머리판·유탄발사기 변형을 포함합니다. 설정은 `MSL_freeWeaponFamilies`에서 관리합니다.

원본 추출 목록에 포함되고 실제 설치된 공개 보병 무기만 판매 목록에 들어갑니다. 기존 부착물 일체형 중복/내부/사용 후 무기 제외 필터는 유지합니다. 별도 부착물과 탄약은 기존 유료 규칙을 따릅니다. 무료 무기의 판매 수익은 $0입니다. 다른 구형 무기 계열은 기존 가격을 유지합니다.
