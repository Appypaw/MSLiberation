# 장비 추출 목록 반영 (2026-10-26)

사용자가 게임에서 추출한 목록의 클래스 식별자만 가져옵니다. 11,032개 CfgWeapons, 2,618개 CfgMagazines, 1,337개 배낭, 261개 안경류가 원본 후보입니다. 실제 상점 수는 설치 모드와 공개/보병 장비 필터에 따라 줄어듭니다.

`presets/msl/imported_equipment.sqf`를 `scripts/msl/import_equipment.sqf`에서 읽어 서버 상점 목록을 구성합니다. 바닐라는 추출 목록에 지정한 필수품만 포함됩니다. 기존 무기와 부착물의 명시적 가격/레벨을 우선합니다. 추가 품목은 엔진의 실제 장비 종류·성능에 따라 기존 장비 티어와 신규 탄약 티어를 적용합니다. 추가 무기의 기본값은 권총 $500/Lv1, 소총 $1200/Lv2, 기관단총 $900/Lv1, 산탄총 $800/Lv1, 기관총 $2800/Lv4, 저격총 $3200/Lv4, 유탄발사기 $1600/Lv3, 발사기 $2500/Lv4, 유도 발사기 $6500/Lv7입니다. 기존 클래스별 가격표가 이 기본값보다 우선합니다.

## 탄약과 폭발물

차량 탄약은 판매하지 않습니다. 허용된 보병 무기의 모든 총구(총열/부착 유탄발사기 포함), Throw 및 Put에서 실제 사용할 수 있는 추출 탄약만 포함합니다. 유탄·수류탄·연막·조명탄·지뢰·폭약도 대상입니다. 다른 모드나 바닐라 탄약은 추출 후보에 없으면 자동으로 추가되지 않습니다.

## 아군 복장

PRACS RACS 군복(특수복 포함)과 비방탄 모자는 **Lv0 / $0**으로 최종 적용합니다. SLA 복장은 이 예외에서 제외합니다. 방탄복·방탄헬멧·배낭·야시경은 기존 성능별 가격과 레벨을 유지합니다. 무료 복장의 판매 수익도 $0입니다. 플레이어 레벨/누적 XP 표는 그대로이며 Lv0 품목은 처음부터 구매할 수 있습니다.

무기고 검색에 `PRACS`, `uniform`, `beret` 또는 품목 이름을 입력하면 200개 표시 제한 밖의 장비도 찾을 수 있습니다. 기존 착용 슬롯은 비워야 교체할 수 있습니다.

## 적용

미션 PBO를 교체하고 미션을 재시작해야 적용됩니다. 캠페인 진행·자금·XP 저장 형식은 변경하지 않습니다. 엔진 초기화 시 `[MSL IMPORT]`에 실제 수량을 기록합니다. `tools/msl_selftest.sqf`는 공개 품목·탄약·무료 군복 규칙을 검사합니다.
